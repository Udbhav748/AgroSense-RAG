# _recycle_bin

Files here were moved out of the active tree during a repository cleanup pass (2026-09-21), to keep the Module 10 submission path easy to navigate. They were intentionally retained, not deleted, and remain fully recoverable via `git mv`/`git log --follow`.

Nothing in this directory is part of the active application, tests, or Module 10 submission flow. If anything here is ever restored to active use, re-validate it (references, correctness, currency) before treating it as current implementation or evidence.

- `root-prompts/` — old root-level prompt/notes files with no active references.
- `docs-planning-history/` — historical/aspirational planning docs, superseded or unreferenced.
- `legacy-eval-code/` — a superseded predecessor script, replaced by a current tool.
- `legacy-eval-results/` — uncited historical evaluation-result captures.
